# Fruit Slice 🍉

เกมฟันผลไม้สไตล์ Fruit Ninja ทำด้วย HTML/CSS/JavaScript ล้วน (ไม่ใช้ไลบรารีภายนอก)

## โครงสร้างโปรเจกต์
- `index.html` - หน้าหลักของเกม
- `css/style.css` - ตกแต่งสไตล์และ UI
- `js/game.js` - Logic การทำงานของเกมด้วย HTML5 Canvas
- `sw.js` - รองรับการเล่นแบบ Offline (PWA)
- `manifest.json` - ตั้งค่า Web Application
